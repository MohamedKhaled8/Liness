# Splash Screen - شاشة البداية

## نظرة عامة
تم تصميم شاشة البداية (Splash Screen) بشكل احترافي يليق بالتطبيق التعليمي مع مراعاة:
- ✅ **تصميم تعليمي احترافي** يعكس هوية التطبيق
- ✅ **Responsive بالكامل** يتكيف مع جميع أحجام الشاشات
- ✅ **دعم الوضع الليلي والنهاري** (Dark/Light Mode)
- ✅ **Animations سلسة ومتقدمة**
- ✅ **لم يتم المساس بأي Logic موجود**

## المميزات الرئيسية

### 1. الرسوم المتحركة (Animations)
- **Logo Animation**: حركة مرنة (Elastic) للشعار مع تأثير الظهور التدريجي
- **Text Animation**: انزلاق وظهور تدريجي للنص
- **Particles Animation**: جزيئات متحركة في الخلفية تعطي حيوية للشاشة
- **Progress Indicator**: شريط تقدم متحرك يوضح عملية التحميل

### 2. التصميم التعليمي
- **أيقونة تعليمية**: استخدام أيقونة المدرسة (school_rounded) كشعار رئيسي
- **ألوان متناسقة**: استخدام ألوان التطبيق الأساسية (mainBlue, lightBlue)
- **نص عربي واضح**: "رحلتك التعليمية تبدأ هنا" كشعار تحفيزي
- **جزيئات تعليمية**: رسومات كتب صغيرة متحركة في الخلفية

### 3. الاستجابة (Responsiveness)
جميع العناصر تستخدم نسب من حجم الشاشة:
```dart
width: size.width * 0.35  // 35% من عرض الشاشة
fontSize: size.width * 0.12  // 12% من عرض الشاشة
```

### 4. دعم الثيمات
- **الوضع النهاري**: خلفية بيضاء مع تدرجات زرقاء خفيفة
- **الوضع الليلي**: خلفية داكنة مع تدرجات زرقاء متوهجة

## البنية التقنية

### Animation Controllers
```dart
_logoController      // للتحكم في حركة الشعار
_textController      // للتحكم في حركة النص
_particlesController // للتحكم في الجزيئات المتحركة
_progressController  // للتحكم في شريط التقدم
```

### التوقيت
- **0ms**: بدء حركة الشعار
- **500ms**: بدء حركة النص
- **800ms**: بدء شريط التقدم
- **3000ms**: الانتقال للشاشة التالية (OnBoarding)

## التخصيص

### تغيير مدة العرض
```dart
Timer(const Duration(seconds: 3), () {  // غيّر 3 إلى المدة المطلوبة
  Navigator.of(context).pushReplacementNamed(Routes.onBardingScreen);
});
```

### تغيير الشعار
استبدل:
```dart
Icon(
  Icons.school_rounded,  // غيّر الأيقونة هنا
  size: size.width * 0.18,
  color: ColorsManger.white,
)
```

### تغيير النصوص
```dart
'Liness'  // اسم التطبيق
'رحلتك التعليمية تبدأ هنا'  // الشعار
'جاري التحميل...'  // نص التحميل
```

## الملفات المعدلة
- ✅ تم إنشاء: `lib/feature/splash_screen_feature/splash_screen.dart`
- ✅ لم يتم تعديل أي Logic موجود
- ✅ متوافق مع الـ Router الحالي

## الاستخدام
الشاشة تعمل تلقائياً كـ `initialRoute` في التطبيق:
```dart
initialRoute: Routes.splashScreen,
```

## ملاحظات تقنية
- استخدام `TickerProviderStateMixin` لدعم Animations متعددة
- استخدام `CustomPainter` لرسم الجزيئات المتحركة
- معالجة `mounted` للتأكد من عدم حدوث أخطاء بعد dispose
- تنظيف الموارد في `dispose()` لتجنب memory leaks

## الأداء
- ⚡ Animations خفيفة وسلسة
- ⚡ لا تؤثر على وقت التحميل
- ⚡ استخدام فعّال للموارد
